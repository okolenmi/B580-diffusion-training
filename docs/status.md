## Declared but not working

- Graph setting `memory.ram_max_mb` (a stated host-RAM ceiling) is checked at admission and enforced by the child; built and CPU-tested, enforced and
  refused on a real child process in `tests/browser/check_runs` (a tiny model; the count is `RssAnon + RssShmem`); a real SDXL run is `TESTING.md` Critical C.4. `auto` is not checked. See `internals/memory.md`, "Host memory".

## Not built

- Event-trigger buttons in views (they need a control channel).
- Block swap (denoiser blocks held on the host; Anima may need it, SDXL does not): no setting, no family block layout, no engine code (`internals/memory.md`, "Open").
- Weights shared between processes: measured not possible with plain torch (`internals/parallel-runs.md`); every run holds its own copy.
- Custom kernels for the frozen-weight path beyond what `xpu-kernels` provides (`internals/kernels.md`, `internals/capturable-attention.md`).

## Waiting on hardware

`TESTING.md`: the Critical list (the unattended lab, the quantization probe, real weights through the apps page), then the optional items; research runs are in `experiments-to-run.md`.
